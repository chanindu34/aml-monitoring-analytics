# Tableau Data Dictionary

Generated by `scripts/10_export_tableau.py`. All files live in `outputs/tableau/`.

| File | Rows | Grain | Dashboard | Purpose |
|---|---:|---|---|---|
| `risk_cube.csv` | 128,200 | date x hour x payment format x currency x amount band | 1 Executive Risk | Filterable laundering volume/rate by every risk dimension; includes tail flag |
| `segment_risk.csv` | 69 | one row per segment of each risk dimension | 1 Executive Risk | Laundering rate, 95% Wilson CI, lift, p-value, Bonferroni significance |
| `kpi_headline.csv` | 1 | single row | 1 Executive Risk | Headline KPI tiles (analysis window, tail excluded) |
| `typology_summary.csv` | 10 | one row per typology | 2 Laundering Behaviour | Volume, value, AML stage, difficulty + behavioural fingerprint |
| `account_feature_comparison.csv` | 15 | one row per account feature | 2 Laundering Behaviour | Laundering vs normal medians + univariate AUC |
| `account_scores.csv` | 372,954 | one row per account active in test period (Sep 6-10) | 3 Rules vs ML What-If | ML scores + ranks + rule flags + laundering group; drives the alert-budget slider |
| `rule_performance.csv` | 8 | one row per rule (full window) | 3 Rules vs ML What-If | Alerts, precision, recall, lift, cost per true positive |
| `rule_threshold_sweep.csv` | 73 | rule x threshold (full window) | 3 Rules vs ML What-If | Precision/recall trade-off curves for R1, R2, R6 |
| `rule_typology_coverage.csv` | 72 | rule x typology (full window) | 2 Laundering Behaviour | Which typologies each rule catches |
| `ml_vs_rules.csv` | 7 | one row per rule (test period) | 3 Rules vs ML What-If | Head-to-head at identical alert budgets |
| `ml_capacity_curve.csv` | 32 | model x alert budget (test period) | 3 Rules vs ML What-If | Precision/recall of each model across alert budgets |
| `ml_permutation_importance.csv` | 15 | one row per feature (15-feature study) | 3 Rules vs ML What-If | Test-set permutation importance vs gain importance |
| `ml_bootstrap.csv` | 2 | one row per headline metric | 3 Rules vs ML What-If | Bootstrap 95% CIs for PR-AUC and gain vs R3 |
| `ml_ablation.csv` | 4 | one row per model variant | 3 Rules vs ML What-If | Ablation x seed stability results |
